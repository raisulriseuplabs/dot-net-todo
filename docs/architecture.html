Where it runs

Today the API runs inside the SDK container that ./dotnet.sh starts; Phase 6 will publish it into a slim runtime image. The application code is identical in both — only the container around it changes.

Left, what exists today: the SDK image is the only .NET on the machine, so the app runs from source inside it and todo.db is an ordinary file in your working copy. Right, what Phase 6 adds (dashed): a multi-stage build so the shipped image carries only the runtime and the published DLL, with the database on a volume. Port and image change; Program.cs does not.

The request pipeline

Every request descends this stack and its response climbs back up through the same layers. The two middleware at the top do nothing on the way down — they exist to reshape what comes back up.

One write, end to end

POST /api/todos is the request that touches every component. The dashed returns show where it can stop early.
